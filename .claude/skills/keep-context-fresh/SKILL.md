# Keep context fresh

## When to use

- Mid-conversation, whenever the person mentions something worth remembering for next time: a new customer, a customer who pays late, a change to VAT or the accountant, a new regular bill, a preference about how you write to them.
- Quarterly, or when the person asks "is my context still right" or "check my notes".

## What you need

- The relevant file under `context/`: `business.md`, `money.md`, `people.md` or `voice.md`.

## Steps

1. Spot the new fact as it comes up naturally. Do not interrupt the flow of conversation to go hunting for these; just notice them.
2. Work out which file it belongs in:
   - A customer, supplier or adviser, and how formal to be with them: `people.md`.
   - What the business does, its offer, its customers: `business.md`.
   - Their accounts software, bank, VAT, tax, regular bills, customers who pay late: `money.md`.
   - How the person likes things written or said: `voice.md`.
3. Propose the one line you'd add or change, in the person's own words where you can.
4. Wait for a yes before editing anything.
5. Once they agree, make the smallest edit that captures the fact, keeping the rest of the file as it is.

## Quarterly check

1. Read through each `context/` file.
2. For anything that looks like it might be out of date (an old price, a regular bill that has stopped, a customer who now pays on time), ask the person directly: "Is this still true?"
3. Only change what they confirm needs changing.

## Rules

- Never edit a context file without an explicit yes first.
- Keep edits small and specific. Do not rewrite a whole file when one line changed.
- If a file still says "Status: not filled in yet", treat any new fact as a reason to start filling it in, with the person's agreement, rather than leaving it blank.

## What to say to the person

"You mentioned Greenway Café always pays 2 weeks late. Shall I add that to your money notes, so I chase them earlier?"

## If something is missing

If the right context file does not exist yet or is empty, say so, propose the first line for it, and create it only once the person agrees.
