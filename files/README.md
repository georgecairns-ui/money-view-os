# Files

Your finance papers, kept next to your money view. Money View reads your accounts software, not files, so nothing here feeds the numbers: this is a tidy place for things you want to keep.

| Folder | For |
|---|---|
| `05-finance` | Invoices, receipts, tax and VAT papers |
| `99-archive` | Old things worth keeping |

Claude suggests where things go and only moves anything once you agree. Change the folders to suit you: ask Claude, for example "add a folder for receipts".

## Where things really live
